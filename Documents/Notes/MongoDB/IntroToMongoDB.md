# What is MongoDB Atlas

MongoDB can be instanced and ran on its own, but with Atlas users get a secure, flexible, and resilient DataBase-as-a-Service (DBaaS).

With Atlas, MongoDB is managed automatically. As a DBaaS, Atlas automates and enhances processes for db management, including deployment, monitoring, backup + restoration, and archiving.

Atlas provides built-in replication for all db deployments.

There are two cluster options: flex or dedicated.

Flex clusters are ideal for sparse or infrequent workloads.

Dedicated clusters are larger and can be customized for specific needs, preferred for production workloads.

There are also free-forever clusters, which can run small projects indefinitely.

Atlas can be managed with Atlas UI, Atlas CLI, or admin API.

Atlas has drivers for every major programming language and supports a variety of frameworks and ODMs to make building an app easier.

Atlas offers both text and semantic searches.

Atlas has built in data visualization with a tool called Atlas Charts.

Atlas also supports a wide range of workflow integrations:

-- Kubernetes Operator
-- AWS CloudFormation
-- Terraform

Atlas Data Federation is a data integration tool that allows a user to qeury, transform, aggregate, and write data across various sources inside and outside of MongoDB Atlas.

Atlas Stream Processing offers a way to process and unify complex data from streaming platforms such as Apache Kafka. This feature enables continous, real-time data processing, validation, and merging.

Using SQL interface, you can easily integrate familiar tooling to run SQL qeuries on your MongoDB collections.

With the Relational Migrator, you can transition your relational workloads to Atlas, convert your application code, and make schema mapping decisions to take full advantage of MongoDB's document model.

Combined, these services features provide a comprehensive set of tools for users to build scalable, synamic applications.
